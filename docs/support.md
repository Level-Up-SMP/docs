# :gem: Support the Server

Level Up SMP is community-funded. If you'd like to help keep the lights on -- and pick up some perks while you're at it -- becoming a **Supporter** is the way to do it.

## Where Your Support Goes

This isn't a money-making operation -- Trodd is footing the bill personally. Donations go directly back into the server: hosting, memory and disk upgrades as the world grows, and paying for the development work that keeps things running and lets us build custom features.

More custom features and improvements are on the way — supporter contributions help us get there sooner.

## How to Donate

Monetary contributions can be sent via PayPal to [TroddTV](https://paypal.me/toddsheppard88).

Donate **$5 USD or more** and you'll be granted the **Supporter** role for the duration of the server.

## Supporter Perks

As a Supporter, you'll get:

* A ⭐ next to your name in game
* A **Supporter** role on our Discord, plus access to a supporters-only channel
* Up to **3 homes** via `/home` and `/sethome`
* Free access to the [HeadDatabase](https://minecraft-heads.com/) with `/hdb search` _(normally 1 diamond per head)_
* The `/hat` command — wear most blocks on your head
* Basic **WorldEdit** access in the `Creative World`
* The `/tpr` random-teleport command _(once per hour)_
* Access to the `/beezooka` and `/kittycannon` commands
* Live skin changes and updates via [SkinsRestorer](https://modrinth.com/plugin/skinsrestorer) (`/skin set <name|url>`, `/skin update`)

### Crafting Station Commands

Open any of these from anywhere — no need to find or place the block:

* `/anvil`
* `/cartographytable`
* `/grindstone`
* `/loom`
* `/smithingtable`
* `/stonecutter`
* `/workbench`

## Thanks

Every contribution — big or small — helps cover hosting, plugins, and the day-to-day running of the server. We appreciate it.
