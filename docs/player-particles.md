# :sparkles: Player Particles

[PlayerParticles](https://modrinth.com/plugin/playerparticles) is a **Supporter** perk that lets you customize trailing particle effects that follow you around. Pick from dozens of effects (flames, hearts, notes, redstone, etc.) and styles (orbit, spiral, halo, point, and more).

## Basic Usage

The easiest way to manage your particles is through the in-game menu:

* `/pp gui` — Open the menu (recommended for most actions)
* `/pp` — Same as above

Command-line alternatives:

| Command                       | Description                                    |
| ----------------------------- | ---------------------------------------------- |
| `/pp add <effect> <style>`    | Add a particle (e.g., `/pp add flame normal`)  |
| `/pp remove <id>`             | Remove a single particle by ID                 |
| `/pp list`                    | List your active particles                     |
| `/pp toggle`                  | Toggle all your particles on or off            |
| `/pp reset`                   | Clear all your particles                       |
| `/pp groups save <name>`      | Save your current particles as a preset        |
| `/pp groups load <name>`      | Load a saved preset                            |
| `/pp help`                    | Show the full command reference                |

Tip: `/pp toggle` is the quickest way to turn particles off temporarily without losing your settings.

## Rules of Use

To keep particles fun for everyone:

1. **No view-blocking or noisy effects in shared spaces.** Avoid dense, screen-filling, or sound-producing particles at spawn, the shopping district, and other gathering areas.
2. **Be considerate in builds and parkour.** Don't use particles that obscure jumps, signs, or other players' work.
3. **Keep it reasonable.** Stacking many simultaneous particles is laggy for nearby players.
4. **No harassment.** Don't use particles to grief, mislead, or annoy other players.

Staff may ask you to disable specific particles, or clear them entirely, if they're causing problems.

## Tips

* **Toggle off when you're AFK.** Particles tick continuously while you're online. If you're going to be idle for a long stretch — AFK farming, overnight, etc. — running `/pp toggle` reduces unnecessary server load for everyone. Not enforced, just appreciated.
